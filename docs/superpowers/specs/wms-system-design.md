# WMS 立库系统设计文档

## 1. 项目背景

客户定制的 WMS 立库系统，私有化部署于客户工厂内网环境。覆盖原材料仓、帮面仓和大底仓、裁片仓（平库）四个仓库，需与 WCS/PLC/AGV 中台/MES/ERP 五个外部系统集成。

---

## 5. 核心业务流程

### 5.1 入库流程

**来源**：成品下线（一期 WMS 手动创建 + PDA 扫码，MES 推送预留）

**流程**：
```
MES推送入库单(一期手动创建) → 满托优先排序 → 库位分配(指定/系统推荐) → 下发WCS → 上架 → 库存+1
```

**规则**：
- 单品单托（一托一料）
- 满托优先入库（多托待入时满托排前面先入）
- 库位分配：支持指定库位和系统推荐两种模式
- 入库失败：自动换库位重试（最多 10 次），超限通知人工

### 5.1.1 库位自动分配逻辑

**分配模式**：指定库位（人工选择）/ 系统推荐（自动分配，默认）

**自动分配流程**：

```
收货/质检完成 → 读取物料+仓库对应的上架策略
    → Step1: 过滤可用库位
    → Step2: 优先级打分排序
    → Step3: 推荐 Top1 库位（失败自动取 Top2、Top3...）
    → Step4: 锁定库位（状态置为预占）→ 下发 WCS
```

**Step1 — 过滤可用库位（硬约束，不满足直接排除）**：

| 过滤条件 | 规则 |
|---------|------|
| 库位状态 | 仅选择状态 = 空闲的库位，排除预占/占用/冻结/禁用/维修 |
| 承重校验 | 库位最大承重 ≥ 托盘总重量（物料重量 + 托盘自重） |
| 尺寸校验 | 库位长 × 宽 × 高 ≥ 托盘外形尺寸 |
| 混放规则 | 一期单品单托，库位必须为空（无其他托盘）；二期扩展同 SKU 同批次混放 |
| 库区限制 | 库位所属库区允许存放该物料类型 |

**Step2 — 优先级打分排序（软约束，按权重计算得分）**：

| 优先级因素 | 权重 | 打分规则 |
|-----------|------|---------|
| 同物料就近聚集 | 40% | 同巷道已有同物料 +40 分；相邻巷道有同物料 +20 分；无同物料 +0 分 |
| 通道距离 | 25% | 靠近出库口/主通道 +25 分；次通道 +15 分；深处 +5 分 |
| 层数（黄金层） | 20% | 中层（便于存取）+20 分；低层 +10 分；高层 +5 分 |
| 空库位优先 | 15% | 完整空库位 +15 分；（一期单品单托，此项始终满分） |

> 权重可在 `wms_strategy` 表中按仓库/库区/物料类型配置，上述为默认值。

**Step3 — 异常兜底策略**：

| 异常场景 | 处理方式 |
|---------|---------|
| 有可用库位但上架失败 | 自动选择下一个得分最高的库位重试，最多 10 次 |
| 所有库位均不满足过滤条件 | 自动推荐暂存区库位，同时触发满仓预警通知仓库主管 |
| 暂存区也满 | 拦截上架，站内消息 + 系统弹窗通知人工处理 |
| 重试 10 次仍失败 | 任务状态置为异常挂起（70），通知人工介入 |

### 5.2 出库流程

**触发**：领料单下发 → 自动生成出库任务

**流程**：
```
领料单 → FIFO选定托盘 → 锁定库存 → 下发WCS → 整托出库 → WCS确认完成 → 扣账 → 余料回库(独立入库任务)
```

**规则**：
- 策略：FIFO（先进先出）为主
- 方式：整托出库
- 扣账时机：WCS 反馈出库完成后扣账
- 余料处理：未用完的物料生成独立入库任务重新入库
- 防重复出库：同一托盘同时只能被一个出库单锁定

### 5.3 盘点流程

**方式**：全盘 + 循环盘 + 抽盘

**执行**：
- 立库：货到人（等同一次出库 → 盘点台清点 → 回库），库位在出库时自动释放
- 平库：人到货（PDA 扫码核对）

**冻结机制**：
```
扫描货架A → 冻结货架A → 盘点 → 提交结果 → 释放货架A → 扫描货架B → ...
```
- 逐架冻结：扫描哪个货架冻结哪个，提交结果后释放
- 冻结期间：其他入库/出库/移库任务跳过该货架

**差异处理**：人工手动调账

**频率**：每周一次（定时触发）

### 5.4 移库流程

- 触发方式：系统自动整理（同物料聚集、库位均衡）+ 人工指定
- 直接执行，无需审批

### 5.5 配套任务

- BOM 来源：MES 推送为主，WMS 也可自维护
- 齐套动作：仅提示（站内消息/看板显示"已齐套"）
- 不自动触发出库/分拣

### 5.6 分拣流程

**流程**：
```
分拣单(关联领料单) → 生成出库任务(可多托) → 整托出到分拣台 → 系统显示需拣数量 → 人工拣完确认 → 余料回库 → 分拣好的物料放指定站点 → AGV搬到产线
```

**规则**：
- 分拣台可动态增减
- 一个分拣单可触发多托出库
- 余料生成独立入库任务回库
- 空架生成空架回收任务

## 6. 任务状态机

### 6.1 入库任务

```
待处理(0) → 已分配库位(10) → 已下发WCS(20) → 执行中(30) → 上架完成(40) → 已完成(50)
                                    ↓
                              执行失败(60) → 自动换位重试 → 已下发WCS(20)
                                    ↓ (重试10次)
                              异常挂起(70) → 人工处理 → 重新下发 → 已下发WCS(20)
                                           → 手动关闭(80)

待处理(0) → 已取消(90)  // 仅待处理状态可取消
```

### 6.2 出库任务

```
待处理(0) → 已锁定库存(10) → 已下发WCS(20) → 执行中(30) → 出库到位(40) → 已扣账(50) → 已完成(60)
                                    ↓
                              执行失败(70) → 重试/异常挂起(80)

出库完成后如有余料 → 生成独立入库任务
```

### 6.3 移库任务

```
待处理(0) → 已下发WCS(10) → 执行中(20) → 移库完成(30) → 已完成(40)
                                ↓
                          执行失败(50) → 重试/异常挂起(60)
```

### 6.4 盘点任务

```
待处理(0) → 盘点中(10) → 已提交(20) → 无差异 → 已完成(50)
                                      → 有差异 → 待调账(30) → 已调账(40) → 已完成(50)
```

### 6.5 分拣任务

```
待处理(0) → 已生成出库单(10) → 出库中(20) → 到达分拣台(30) → 分拣中(40) → 分拣完成(50) → 已完成(60)
```

### 6.6 通用规则

- 状态值用 tinyint 枚举，留间隔（0/10/20/30...）方便后续插入中间状态
- 仅"待处理"状态可取消，已下发 WCS 后禁止取消
- WCS 指令幂等：任务编号作为幂等键

## 7. 数据模型

### 7.1 基础数据域

#### 仓库结构

| 表 | 核心字段 | 说明 |
|---|---|---|
| wms_warehouse | 编码、名称、类型（立库/平库）、地址、状态 | 4 个仓库 |
| wms_zone | 所属仓库、编码、名称、允许物料类型 | 库区 |
| wms_rack | 所属库区、巷道号、列数、层数、排 | 货架 |
| wms_location | 所属货架、位置编码（巷-列-层）、巷道号、列号、层号、状态（空闲/预占/占用/冻结/禁用/维修）、最大承重、最大长度、最大宽度、最大高度、库位类型（普通/暂存区/地堆）、当前托盘ID | 库位 |

库位状态流转：`空闲 → 预占（分配后）→ 占用（上架完成）→ 冻结（盘点中）→ 空闲（出库/盘点释放）`

#### 载具与绑定

| 表 | 核心字段 |

### 7.2 库存域

| 表 | 用途 | 核心字段 |
|---|---|---|
| wms_inventory | 库存现量（实时余额） | 物料ID、库位ID、托盘ID、批次号、数量、生产日期、过期日期、锁定数量、version（乐观锁） |

- `wms_inventory`：`(物料ID, 库位ID)` 联合唯一索引

## 8. 并发控制

| 场景 | 方案 |
|------|------|
| 库位分配 | Redis 分布式锁（按库位编号加锁）+ 数据库库位状态字段（空闲/预占/占用/冻结/禁用/维修） |
| 库存扣减 | 数据库乐观锁（version 字段）+ 业务层先锁定库存再下发 WCS |
| 防重复出库 | 出库单 + 托盘维度唯一约束，同一托盘同时只能被一个出库单锁定 |
| WCS 指令幂等 | 任务编号作为幂等键，WCS 重复收到同一指令不会重复执行 |
| 盘点冻结 | 逐架冻结，其他任务跳过被冻结的货架 |

## 9. 预警与异常处理

### 9.1 预警类型

| 类型 | 触发条件 | 通知方式 |
|------|---------|---------|
| 最低库存量 | 物料库存低于安全库存 | 站内消息 + 系统弹窗 |
| 临期预警 | 物料接近过期日期 | 站内消息 + 系统弹窗 |
| 设备故障 | WCS/AGV 反馈设备异常 | 站内消息 + 系统弹窗 |
| 任务超时 | 任务长时间未完成 | 站内消息 + 系统弹窗 |
| 满仓预警 | 库区使用率超过阈值 | 站内消息 + 系统弹窗 |

### 9.2 WCS/AGV 异常处理

- 超时判定：下发指令后 2 分钟无响应
- 处理流程：自动重试（最多 10 次）→ 通知人工 → 人工解决后可重新下发

## 11. 可视化与看板

### 11.1 货位可视化

一期采用表格/网格色块矩阵：
- 行列层展示，颜色区分状态（空闲/占用/冻结/禁用/维修）
- 支持按巷道/层切换查看

### 11.2 仓库看板

内容：
- 实时任务状态（入库中/出库中/移库中数量）
- 库区使用率
- 设备状态（堆垛机/AGV 在线/故障/充电）
- 今日出入库统计
- 系统状态（CPU/内存/磁盘/服务连接状态）

部署方式：
- 管理后台内嵌页面（需登录）
- 独立大屏页面（无需登录，挂仓库墙上电视）

刷新方式：WebSocket 实时推送

## 12. 外部系统对接

### 12.1 WCS 对接（REST API）

| 接口 | 方向 | 说明 |
|------|------|------|
| 上架指令 | WMS → WCS | 指定源位置、目标库位 |
| 下架指令 | WMS → WCS | 指定源库位、目标位置（出库口/分拣台） |
| 移库指令 | WMS → WCS | 指定源库位、目标库位 |
| 执行反馈 | WCS → WMS | 任务执行结果回调 |

### 12.2 AGV 中台对接

| 接口 | 方向 | 说明 |
|------|------|------|
| 搬运任务 | WMS → AGV | 指定 AGV、起始站点、目标站点 |
| 执行反馈 | AGV → WMS | 搬运结果回调 |
| 充电通知 | AGV → WMS | AGV 进入充电状态 |
| 故障通知 | AGV → WMS | AGV 故障，WMS 暂停向该 AGV 下发指令 |

### 12.3 MES/ERP 对接（一期预留）

| 接口 | 方向 | 说明 |
|------|------|------|
| 入库单推送 | MES → WMS | 成品下线入库通知 |
| BOM 推送 | MES → WMS | 配套 BOM 清单 |
| 物料信息 | MES/ERP → WMS | 物料基础数据 |
| 库存查询 | MES/ERP → WMS | 查询库位/库存数据 |

一期：预留接口定义（Controller + DTO），用 Mock 数据跑通流程。物料主数据由 WMS 手动录入 + Excel 导入。
