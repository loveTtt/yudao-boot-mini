# 2026-04-22 wms 残留统一清理设计

作者：Codex  
日期：2026-04-22

## 目标

在当前项目内统一清理 `wms` 残留，优先保证运行时配置、代码引用、变量命名、工程元数据与文档展示的一致性。

## 范围

1. 运行时配置前缀：`wms.*` → `wms.*`
2. Java 代码中的配置引用：
   - `@ConfigurationProperties`
   - `@ConditionalOnProperty`
   - `@Value("${...}")`
   - `${wms.xxx}` 占位符
3. 变量名与测试常量中的 `wms`
4. 文档、注释、示例值、`.idea` 工程配置中的 `wms`

## 保守边界

以下内容不做无脑替换，避免影响当前功能：

1. 数据库真实表名与序列名
2. 可能影响外部系统可达性的真实第三方地址
3. 历史 issue / pull request 链接中的仓库路径

## 实施顺序

1. 先改运行时配置前缀与代码引用
2. 再改变量名与测试常量
3. 再改文档、示例值、IDE 配置
4. 最后复扫残留项，输出保留原因

## 验证方式

1. 全局检索 `wms.`、`wms`、`Wms`
2. 确认运行时代码中不再引用旧配置前缀
3. 对保留项逐一说明原因
